# Напоминания о встречах за 0 минут в Outlook classic

Этот VBA-код автоматически заменяет напоминания организаторов на одно штатное
напоминание Outlook в момент начала встречи.

Обрабатываются только встречи с заданным временем в основном календаре текущего
профиля Outlook. Личные записи без участников, события на весь день, отменённые,
отклонённые и уже начавшиеся встречи не изменяются.

Если у подходящей встречи напоминание было выключено, код принудительно включает
его и устанавливает значение `0 минут`. Это намеренное поведение: требование
«всегда напоминать в момент начала» имеет приоритет над прежним локальным
отключением напоминания.

## Требования

- Windows и **Outlook classic**. Новый Outlook не поддерживает VBA.
- Разрешение на запуск VBA-макросов в Outlook.
- Включённый показ напоминаний Outlook и разрешённые уведомления Outlook в Windows.

## Установка

1. Полностью переключитесь на Outlook classic. Если в правом верхнем углу есть
   переключатель **New Outlook / Новый Outlook**, он должен быть выключен.
2. В Outlook нажмите `Alt+F11`, чтобы открыть Microsoft Visual Basic for
   Applications.
3. В левой панели **Project Explorer** раскройте `Project1 (VbaProject.OTM)` →
   `Microsoft Outlook Objects` и дважды нажмите `ThisOutlookSession`.
4. Если в `ThisOutlookSession` уже есть код, сохраните его копию. В одном модуле
   нельзя иметь два обработчика одного события: перенесите существующее
   содержимое `Application_Startup`, `Application_MAPILogonComplete` и
   `Application_Quit` внутрь одноимённых обработчиков из поставляемого файла.
   Остальные существующие процедуры можно оставить рядом с добавляемым кодом.
5. Скопируйте всё содержимое файла `ThisOutlookSession.vba` в окно
   `ThisOutlookSession`.
6. В редакторе VBA выберите **Debug → Compile VBAProject**. Ошибок компиляции
   быть не должно.
7. Нажмите `Ctrl+S`, закройте редактор VBA и Outlook, затем снова запустите
   Outlook. Этот единственный перезапуск завершает установку; в дальнейшем код
   подключается сам при каждом запуске Outlook.

## Безопасность макросов

Откройте в Outlook:

`File → Options → Trust Center → Trust Center Settings → Macro Settings`.

Не выбирайте **Enable all macros**. Предпочтительный вариант:

1. Создать или получить сертификат подписи кода. Для личной установки можно
   использовать `SelfCert.exe`, который входит в Microsoft Office.
2. В редакторе VBA открыть **Tools → Digital Signature**, выбрать сертификат и
   сохранить проект.
3. В Trust Center выбрать режим, разрешающий только подписанные макросы.
4. При первом запросе доверия проверить сертификат и доверить издателю.

Если параметры контролируются организационной политикой, подпись или разрешение
должен предоставить администратор Microsoft 365/Windows.

## Первичная проверка

1. Создайте тестовую встречу с участником на 5–10 минут позже текущего времени и
   установите ей напоминание за 15 минут.
2. Нажмите `Alt+F8`, выберите `ZeroReminder_RepairNow` и нажмите **Run**.
   Этот ручной запуск нужен только для диагностики; обычная работа от него не
   зависит.
3. Откройте тестовую встречу. В поле напоминания должно стоять `0 minutes` /
   `0 минут`.
4. Для просмотра результата диагностики нажмите `Alt+F11`, затем `Ctrl+G`.
   В окне **Immediate** появятся счётчики `Changed`, `Skipped` и `Errors`.
5. Закройте и снова откройте Outlook, создайте ещё одну тестовую встречу с
   напоминанием 15 минут и убедитесь, что оно самостоятельно изменилось на 0.
6. Дождитесь начала тестовой встречи и убедитесь, что Outlook показал штатное
   напоминание.

## Что делает код

- `Application_Startup` при каждом запуске привязывает обработчики к основному
  календарю. `Application_MAPILogonComplete` автоматически повторяет привязку,
  если MAPI-хранилище ещё не было готово при раннем старте Outlook.
- Стартовая проверка использует отдельные ограниченные выборки для будущих
  одиночных встреч и master повторяющихся серий. Если конкретное хранилище не
  поддержит такой фильтр, код автоматически выполнит полный безопасный проход.
- `ItemAdd` исправляет новые и принятые приглашения.
- `ItemChange` восстанавливает 0 минут после обновления встречи организатором.
- Выключенное напоминание подходящей встречи снова включается и получает
  значение 0 минут.
- Перед сохранением код сравнивает значения и не записывает уже исправленную
  встречу повторно.
- Для повторяющейся встречи исправляются master серии и существующие изменённые
  экземпляры. Удалённые и отменённые экземпляры пропускаются.
- Ошибка чтения или сохранения одного элемента записывается в окно **Immediate**
  и не останавливает обработку остальных встреч.

## Ограничения

- Outlook должен быть запущен в момент начала встречи. При закрытом Outlook VBA
  не работает.
- Режим Windows **Do not disturb / Не беспокоить**, Focus Assist или отключённые
  уведомления могут скрыть оповещение.
- Встреча должна синхронизироваться с календарём до времени начала.
- Код изменяет только основной календарь текущего профиля. Общие календари и
  основные календари других подключённых учётных записей не обрабатываются.
- VBA-подпись перестаёт быть действительной после изменения кода; после правок
  проект нужно подписать повторно.

## Удаление

1. Нажмите `Alt+F11` и откройте `ThisOutlookSession`.
2. Удалите добавленный код или восстановите сделанную перед установкой копию.
3. Сохраните VBA-проект и перезапустите Outlook.

Уже изменённые напоминания останутся равными 0; удаление кода не возвращает
исходные значения организаторов.
